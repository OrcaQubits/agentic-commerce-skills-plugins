# v1.1.0 — x402, Trusted Agent Protocol, and commerce readiness

The collection now contains 18 plugins and 300 skills, with native Claude Code sources and generated bundles for Gemini CLI, Codex, Cursor, Antigravity, and OpenClaw.

## New plugins and workflows

- **x402 Agentic Payments:** seven skills and an expert agent covering HTTP and MCP payment negotiation, facilitators, spending policy, migration, and local conformance fixtures.
- **Trusted Agent Protocol:** six skills and an expert agent covering merchant verification, HTTP signatures, key trust, consumer/payment bindings, and local cryptographic and replay fixtures.
- **Commerce Readiness:** an executable readiness audit, remediation guidance, and an MCP server exposing the audit to agents. Payment detection distinguishes structurally valid MPP and x402 challenges from arbitrary HTTP 402 responses; storefront checks account for catch-all pages.
- **Shopify:** new Catalog and Storefront MCP implementation skills.

Implementation skills fetch current official documentation before generating integration code. Dated source baselines and pinned executable fixtures document tested behavior; they do not replace live documentation.

## Fixes and validation

- Corrected plugin repository manifest types and hardened Python hook interpreter fallback, including Windows resource-path checks.
- Refreshed protocol references, marketplace inventories, and generated bundles across all five distribution layouts.
- Added source/distribution validation, payment regressions, offline SDK and cryptographic fixtures, independent installed-bundle tests, and MCP integration checks to CI.
- Fixed the Cursor schema validation failure caused by GitHub HTTP 429 responses. Fetches now use bounded retries, timeouts, and a live GitHub API fallback; unavailable or invalid official schemas still fail the check.
- Updated marketplace release metadata and the root Gemini extension version to 1.1.0. The root Gemini installation remains the UCP extension; the other plugins are available through their platform bundles.

## Install the new Claude Code plugins

```text
/plugin marketplace add OrcaQubits/agentic-commerce-skills-plugins
/plugin install x402-agentic-payments@agentic-commerce
/plugin install trusted-agent-protocol@agentic-commerce
```

See the repository's `INSTALL-*.md` guides for other platforms and each plugin's README for fixture setup.

## Fixture scope

The x402 SDK fixtures use synthetic keys and a mocked facilitator, with no funds transferred or blockchain RPC calls. The TAP fixtures cover the documented Ed25519 subset and an explicitly synthetic container-binding format; they do not certify Visa interoperability or authorize payments. Production integrations require their own durable budget/replay storage, trust configuration, and authorization controls.
