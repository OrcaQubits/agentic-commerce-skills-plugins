# v1.1.1 — Correct native plugin installation and release guidance

This patch fixes distribution issues found while installing the x402 and Trusted Agent Protocol plugins from v1.1.0. Their plugin versions are now 0.1.1. The original v1.1.0 Git tag remains unchanged.

- Antigravity bundles now include a native `plugin.json`, root `skills/`, and `rules/AGENTS.md`. The native installer discovers seven x402 skills and six TAP skills. Legacy `.agent/` files remain available.
- OpenClaw bundles now use its content-bundle loader. Removed the native `openclaw.plugin.json` marker that incorrectly selected the JavaScript plugin loader.
- Corrected repository URLs in generated Gemini, Antigravity, and OpenClaw metadata.
- Replaced stale installation instructions: Gemini accepts a positional directory; Codex uses full plugin bundles; Cursor requires complete local copies instead of external symlinks; executable resources must stay with the skills.
- Added marketplace-resolution, installed-resource, and native OpenClaw installation checks to CI.

See `INSTALL-RELEASE.md` for exact commands on all six platforms and the OpenClaw source-bundle workaround for users staying on v1.1.0. Repository discovery and local installation do not imply publication in curated public directories or ClawHub.

Implementation skills continue to fetch live official documentation. This patch changes packaging and installation guidance, not protocol behavior or fixture coverage.
